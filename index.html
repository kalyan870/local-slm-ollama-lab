Model Size Reference

Edge AI Readiness

Small Language Models (1B-7B parameters) are ideal for edge deployment:

  • Quantized 1B models run on phones & Raspberry Pi
  • 3B-4B models run on laptops without GPU
  • 7B models need ~4-6GB VRAM, run on mid-range GPUs
  • Offline-first — no internet needed after download
  • Privacy — data never leaves your device
